Each gain changes the response in its own way. Start with P only, then add I, then D.

A first-order plant has no overshoot to calm under P alone. With PI, the overshoot comes from the integrator and the controller's zero, so there Kd does not remove it. Use the second-order plant to see the classic D effect.
